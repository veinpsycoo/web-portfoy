Contact et demande de devis

Vous pouvez partager vos besoins via WhatsApp. Il n'est pas nécessaire de remplir un long formulaire pour commencer la discussion ; il suffit d'expliquer votre situation actuelle et votre objectif.

Que devez-vous partager ?

  • Le lien ouvert de votre site actuel, le cas échéant.
  • Le travail que vous souhaitez faire réaliser ou le problème que vous rencontrez.
  • Les textes, visuels ou informations sur des exemples de travaux déjà prêts.
  • Les fonctionnalités dont vous avez besoin : par exemple, une liste de produits, un système d'adhésion, un rapport ou un format vidéo.

Envoi de votre message

Le lien ouvre WhatsApp avec un texte de démarrage prêt. Vous modifiez le texte et finalisez l'envoi ; cliquer sur le lien ne signifie pas que le message a été envoyé ou que l'offre a été acceptée. Cette page ne collecte pas de réponses de formulaire sur son propre serveur. Lorsque vous passez à WhatsApp, les conditions de ce service s'appliquent. Ne partagez pas de mots de passe, de clés API, d'informations de paiement ou de données personnelles de clients dans le premier message.

Comment le périmètre est-il défini ?

Les besoins, l'infrastructure existante, le contenu et les éventuelles connexions avec des systèmes externes sont évalués. Le prix et le délai sont discutés en fonction de ces éléments. Vous pouvez commencer par le guide de préparation du site Web ou le guide de l'étendue de l'automatisation.
