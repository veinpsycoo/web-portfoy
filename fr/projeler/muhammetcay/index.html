Muhammetcay.com: Site de services et portfolio 3D

Mon propre projet · Design et développement. Un site que j'ai préparé pour présenter de manière claire les travaux web, les jeux, les bots, les applications et les vidéos dans un seul portfolio.

Muhammet Çay · 15 novembre 2026

Problème

Placer des travaux de différents types dans une seule longue liste rendait la comparaison des projets difficile. Alors qu'une ouverture visuelle était souhaitée, il fallait également que les liens réels des projets, les descriptions et les moyens de contact soient utilisables.

Décisions de mise en œuvre

  • Un monde tournant avec Three.js sur la page d'accueil, des liens orbitaux et des visuels de projets liés au défilement.
  • Des commandes gauche-droite pour ceux qui souhaitent progresser sans défiler ; une option pour arrêter le mouvement.
  • Des étiquettes distinctes pour les sites clients et les projets personnels ; des pages séparées pour les jeux, les bots, les applications et les vidéos.
  • Contenu lisible dans le premier HTML des services et guides ; la scène 3D ne se charge pas sur ces pages.
  • Liens directs WhatsApp et début de conversation selon le sujet.

Infrastructure et raisons

Le site utilise HTML statique, CSS et JavaScript ; la scène 3D ne fonctionne que sur la page d'accueil. Aucun nouveau framework d'application ou base de données n'était nécessaire pour les pages de contenu. Le déploiement est effectué sur Vercel avec son propre nom de domaine. Des adresses canoniques, un plan du site et des données structurées compatibles avec le contenu visible sont ajoutés aux pages.

Validation et limites

Le menu, les liens de projet, les débordements d'écran mobile, les réponses de page et les objectifs de contact sont vérifiés par des tests de navigateur. La rotation automatique du monde est mesurée sans défilement ; elle est examinée sur les formats bureau et téléphone. Ces contrôles ne sont pas des mesures de données de vitesse d'utilisateur réel ou de classement de recherche. Il n'est pas prétendu qu'un test matériel couvrant tous les appareils physiques a été effectué.
