My website is slow: how to perform correct speed measurement?

First, determine which page is slow on which device and connection. A single PageSpeed score does not represent the experience of all users or permanent performance.

Muhammet Çay · 15 November 2026

Lab data vs. real user data

Lab testing is useful for searching for problems under defined conditions. Real user data, on the other hand, collectively reflects the experience of visitors across different devices and networks. The results of the two do not have to be the same. A new or rarely visited site may not have sufficient field data; in such cases, results are not written as if field measurement exists.

Three different problems

Within Core Web Vitals, LCP evaluates the appearance time of the largest image or text element in the visible area; INP evaluates the interaction response, and CLS evaluates unexpected layout shifts. The fact that the first image loads quickly does not mean that buttons also work quickly. An image loading later and pushing text down is a different user problem than the loading time.

A repeatable measurement record

  • Write the full URL, date, device size, and network conditions.
  • Evaluate the first load and cached reload separately.
  • Observe the problem while the page is loading and while the user is performing an action.
  • Check large images, third-party codes, and the behavior of uploaded videos.
  • Instead of a single instance, examine the distribution of several measurements under the same conditions.
  • After making changes, test not only the score but also the menu, form, and media functions.

Which change first?

Do not install random speed plugins without identifying the source. If a large image delays the initial content, investigate the file size and delivery method; if a long process blocks interaction, investigate the executed code. Try the change in a controlled environment first and maintain the ability to revert. Increasing the score by compromising visual quality or a necessary process does not serve the purpose of the work.

Decision on dynamic sites

The load of a page containing 3D and video is not the same as a text-heavy service page. In this portfolio, 3D remains on the home page; guides and service pages do not load that scene. You can see this distinction in the Project review. You can create a technical review request with a problematic URL and test condition.
