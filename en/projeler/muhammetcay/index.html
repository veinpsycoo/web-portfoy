Muhammetcay.com: 3D portfolio and service site

My own project · Design and development. A site I prepared to present web works, games, bots, applications, and videos clearly in a single portfolio.

Muhammet Çay · 15 November 2026

Problem

Putting different types of work into a single long list made it difficult to compare projects. While a visual opening was desired, actual project links, descriptions, and communication channels also needed to be accessible.

Implementation decisions

  • A rotating world with Three.js, orbital links, and scroll-based project visuals on the homepage.
  • Left-right controls for those who prefer not to scroll; an option to stop movement.
  • Separate tags for client sites and personal projects; separate pages for games, bots, apps, and video.
  • Content readable within the initial HTML for services and guides; the 3D scene does not load on these pages.
  • Direct WhatsApp links and conversation starters based on the topic.

Infrastructure and reasoning

The site uses static HTML, CSS, and JavaScript; the 3D scene only runs on the home page. No new application framework or database was required for the content pages. Deployment is done on Vercel with its own domain. Canonical addresses, sitemaps, and structured data compatible with visible content are added to the pages.

Verification and limits

Menu, project links, mobile screen overflows, page responses, and contact targets are checked with browser tests. Automatic world rotation is measured without scrolling; it is examined in desktop and phone sizes. These checks are not real user speed data or search ranking measurements. It is not claimed that a hardware test covering all physical devices was performed.
